# M1 — Skeleton & infra (buildable SwiftUI shell on simulator)

**Status:** ✅ Completed
**Depends on:** —

## Goal

A buildable SwiftUI app that runs on an iOS 17 simulator with a documented setup, with the app
chrome (nav bar, two-tab bottom bar, drawer, search entry) and design system in place so feature
work drops into a working shell. UI-test target exists with a deterministic stub-mode seam.

## Scope (done)

- [x] XcodeGen project (`project.yml`): app target + UI-test target, iOS 17 deployment, Debug/Release
      configs, `.xcconfig` files. `.xcodeproj` generated and gitignored.
- [x] API-key injection: `Configs/Base.xcconfig` → build setting `LTA_DATAMALL_API_KEY` →
      `Info.plist` (`LTADatamallAPIKey`) → `AppConfig`. Gitignored `Secrets.local.xcconfig`
      (+ committed `Secrets.example.xcconfig`). Fails loudly when missing (parity with the Flutter
      `AssertionError`). Ref: `lib/environment_config.dart`.
- [x] Design system: `Palette` ported from `lib/src/palette.dart` (primary `#25304D`, secondary
      `#969CAE`, accent `#EF3340`, background `#E2EFF5`, Load colors). **Fixed the `LSD`/`LDS`
      Load-color bug** in `BusLoad`.
- [x] Shell: navy nav bar with title "SG Land Transport" + drawer button + search button; custom
      two-tab bottom bar (Nearby / Favorites) persisting to `bottomBarIndex` (raw values 0/1 match
      the Flutter key for clean migration); drawer (Buses / About / Share) with working `ShareLink`.
      Ref: `dashboard_screen.dart`, `main_bottom_app_bar.dart`, `drawer.dart`.
- [x] Info.plist location usage string (parity with current iOS `Runner/Info.plist`).
- [x] UI-test target + `-uiTestStubMode` launch arg; `UITestSupport.prepareIfNeeded()` resets state
      for deterministic tests.
- [x] `README.md` with one-time setup, simulator run, and SG location-simulation instructions.

## Out of scope (deferred)

- Firebase / Crashlytics → **M1b**.
- Real feature content (nearby list, favorites, arrivals, search, about links) → M5/M6.
- Convex bottom-bar styling and hero animation → M7 (placeholder band + simple bar for now).
