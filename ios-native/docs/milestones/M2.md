# M2 — Networking + Codable models (LTAClient)

**Status:** ⬜ Pending
**Depends on:** M1

## Goal

A typed networking layer over `URLSession` that talks to the four LTA Datamall endpoints, decodes
their JSON into Codable domain models, and maps transport/HTTP failures to user-facing messages —
matching the Flutter `BaseRepository` + `CustomException` behavior.

## Scope

- [ ] `LTAClient` over `URLSession`: base `https://datamall2.mytransport.sg/ltaodataservice`, injects
      the `AccountKey` header from `AppConfig.ltaDatamallAPIKey` on every request. Ref:
      `lib/src/features/shared/data/base_repository.dart`.
- [ ] Endpoints (async methods returning decoded models):
  - [ ] `GET /v3/BusArrival?BusStopCode=&ServiceNo=` (ServiceNo optional).
  - [ ] `GET /BusStops?$skip=` (paged 500).
  - [ ] `GET /BusServices?$skip=` (paged 500).
  - [ ] `GET /BusRoutes?$skip=` (paged 500).
  Ref: `lib/src/features/*/data/*_repository.dart`, `ltadatamall.http`.
- [ ] Codable domain models mirroring the Flutter Freezed models (LTA's PascalCase JSON keys):
  - [ ] `BusArrival` (BusStopCode, Services[]), `BusArrivalService` (ServiceNo, Operator, NextBus/2/3,
        + native `inService` flag default true, optional `destinationName`).
  - [ ] `NextBus` (Origin/DestinationCode, EstimatedArrival, Lat/Long, VisitNumber, Load, Feature, Type).
  - [ ] `BusStopValue`, `BusServiceValue`, `BusRouteValue`. Ref: `lib/src/features/*/domain/*`.
- [ ] **Estimated-arrival logic** ported from `next_bus_model.dart`: UTC diff, `≤59s → "Arr"`, else
      `"{n}min"`, empty → `"n/a"`. Use an injectable clock so tests (and UI stub mode) are deterministic.
- [ ] Error mapping → an `LTAError` enum mirroring `CustomException.fromDioError` (no connectivity,
      timeouts, bad certificate, cancelled, 400/404/500/default). Ref: `lib/src/custom_exception.dart`.
- [ ] Stub transport for `-uiTestStubMode` / unit tests: load bundled JSON fixtures instead of the
      network (seam for M5/M6 UI tests).

## Verification

- Unit tests (XCTest) decode real captured JSON for all four endpoints.
- `estimatedArrival` matches the Dart output across known inputs (Arr / Nmin / n/a, boundary at 59s).
- Error mapping unit tests cover each failure case → expected message.
- Fixtures load via the stub transport with no network access.
